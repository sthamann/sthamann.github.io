# Project documentation compatibility

This site provides browser redirects for earlier VEYNDO project documentation addresses after repository renames. It preserves the path suffix, query and fragment. Other project paths are left alone.

GitHub Pages returns a 404 status for unknown paths before the browser redirect runs. This does not redirect binary media requests or clients without JavaScript. Current project content and assets are published by the `sthamann/veyndo` repository. No previous repository name is reused, so GitHub's repository and Git remote redirects remain intact.

The current product website and team page remain hosted on Northflank. This compatibility page serves only the old GitHub Pages address space.
